Deep Dive: Step-by-Step Guide

Phase 1: The Blueprint

Gemini is your AI Architect. Use the Prompt Studio above to define your vision. It automatically generates a strict set of instructions designed specifically for an AI code editor. You can also use MermaidJS to map out flowcharts of your logic!

Phase 2: The AI IDE (Cursor)

An AI IDE is a code editor with a built-in robotic developer. You don't write the code; you just give the orders.

  1. Download an AI IDE like Cursor.
  2. Open a new, empty folder on your computer.
  3. Press Cmd+K (or Ctrl+K) to open the AI prompt bar.
  4. Paste your generated Master Prompt and hit enter. The AI will instantly write your index.html file.
Phase 3: The Launchpad (GitHub)

Now we take your local code and broadcast it to the world using GitHub Pages.

  1. Create a free GitHub account and a new Public Repository.
  2. Drag and drop your completed index.html file into the repository.
  3. Go to Settings > Pages.
  4. Change the source branch to 'main' and save. Your live URL will be ready in 60 seconds.

The Deployment Diagram

1

Create a GitHub Repo

Log into GitHub, click "New Repository," and give it a name like master-realtor-landing. Leave it public.

2

Upload Your Files

Simply drag and drop your local index.html (and any CSS/JS files) from your IDE directly into the browser window of your new repository.

3

Navigate to Settings

Click on the "Settings" tab of your repository, then find the "Pages" menu item on the left sidebar.

4

Go Live

Under "Build and deployment", set the source branch to main, click "Save", and wait a minute for GitHub to generate your live URL!
